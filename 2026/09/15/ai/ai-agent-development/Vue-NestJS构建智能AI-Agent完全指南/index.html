Vue + NestJS 构建智能 AI Agent 完全指南
发表于 2026-09-15| 更新于 2026-09-14|AI
字数总计: 5.5k|阅读时长: 28 分钟

AI Agent 不是简单的”问答机器人”，而是能够自主思考、使用工具、完成复杂任务的智能体。本文将带你用 Vue 3 + NestJS + LangChain 构建一个生产级 AI Agent 应用，从架构设计到完整代码实现，全程干货无废话。

我们会实现一个能够查天气、搜索网络、执行代码的智能助手，并对比 LangChain 和 Vercel AI SDK 两种方案的适用场景。

一、AI Agent 核心概念

什么是 AI Agent？

传统的 LLM 应用只是”对话界面”，而 AI Agent 是一个自主决策系统：

Agent 的四大核心能力

能力 说明 示例
推理（Reasoning） 理解任务，拆解步骤 “查北京天气”需要先获取位置，再调用天气API
工具使用（Tool Use） 调用外部工具/API 调用天气API、数据库查询、代码执行器
记忆（Memory） 记住上下文和历史 记住用户偏好、对话历史
规划（Planning） 制定多步骤计划 拆解”写一篇博客”为”调研→大纲→撰写→优化”

为什么选 LangChain 而非 Vercel AI SDK？

维度 LangChain Vercel AI SDK
Agent 能力 ✅ 完整的 Agent 框架，支持 ReAct、Plan-and-Execute 等 ⚠️ 基础 Tool 调用，Agent 能力有限
工具生态 ✅ 内置 100+ 工具，可自定义 ⚠️ 需手动实现工具逻辑
记忆管理 ✅ 多种记忆策略（对话、摘要、向量） ❌ 需自行实现
复杂度 较高，学习曲线陡 低，API 简洁
适用场景 复杂 Agent 任务 简单对话/流式生成

结论：如果只是做聊天机器人，Vercel AI SDK 足够；如果要构建能自主完成任务的 Agent，LangChain 是唯一选择。

Agent 工作流程

sequenceDiagram
    participant User as 用户
    participant Vue as Vue 前端
    participant Nest as NestJS 后端
    participant Agent as LangChain Agent
    participant Tools as 工具集
    participant LLM as GPT-4
    
    User->>Vue: 输入："查一下北京今天的天气"
    Vue->>Nest: POST /agent/chat (SSE连接)
    Nest->>Agent: 初始化 Agent Executor
    
    Agent->>LLM: 分析任务需要哪些工具
    LLM-->>Agent: 需要调用 weather_tool
    
    Agent->>Tools: 调用 getWeather("北京")
    Tools-->>Agent: {temp: 15, condition: "晴"}
    
    Agent->>LLM: 整合工具结果生成回答
    LLM-->>Agent: "北京今天天气晴朗，温度15°C"
    
    Agent-->>Nest: 流式输出 chunk
    Nest-->>Vue: SSE: data: "北京"
    Nest-->>Vue: SSE: data: "今天"
    Nest-->>Vue: SSE: data: "天气晴朗"
    Vue-->>User: 实时显示回答

八、总结

我们实现了一个完整的 AI Agent 系统：

✅ 后端：NestJS + LangChain，支持工具调用、记忆管理、流式输出
✅ 前端：Vue 3 + TypeScript，SSE 实时通信、工具调用可视化
✅ Agent 能力：天气查询、网络搜索、代码执行
✅ 生产就绪：错误处理、会话管理、性能优化

关键要点

  1. Agent ≠ Chatbot：Agent 能够自主使用工具完成任务
  2. LangChain 适合复杂场景：多步推理、工具编排、记忆管理
  3. Vercel AI SDK 适合简单场景：轻量、易用、快速集成
  4. 流式输出是刚需：提升用户体验的关键
  5. 工具设计要谨慎：清晰的描述 + 安全的执行环境

下一步

  • 集成更多工具（数据库查询、文件操作、API 调用）
  • 实现 Plan-and-Execute Agent（先规划再执行）

  • 接入知识库（RAG）提供领域知识
  • 部署到生产环境（Docker + K8s）
