一、Vercel AI SDK 背景

Vercel AI SDK 是由 Vercel 团队开发的一套开源工具集，专为构建 AI 驱动的应用而设计。它提供了统一的接口来集成各种大语言模型（LLM），包括 OpenAI、Anthropic、Google AI 等，并通过流式传输提供出色的用户体验。

核心优势

  • 统一的 API 接口：无论使用哪家 AI 提供商，都能使用相同的代码结构
  • 流式响应支持：开箱即用的流式传输，提供实时反馈体验
  • 框架无关：支持 React、Vue、Svelte 等主流前端框架
  • 边缘运行时优化：完美适配 Vercel Edge Functions 和其他边缘环境
  • 类型安全：完整的 TypeScript 支持

三、前端层面的流协议

Vercel AI SDK 在前端主要使用 Server-Sent Events (SSE) 协议来实现流式传输。

3.1 SSE 协议原理

sequenceDiagram
    participant Browser as 浏览器
    participant Server as 服务器

    Browser->>Server: GET /api/chat (EventSource)
    Note over Browser,Server: 建立持久连接
    
    loop 服务器推送
        Server-->>Browser: data: chunk1\n\n
        Browser->>Browser: 触发 onmessage
        Server-->>Browser: data: chunk2\n\n
        Browser->>Browser: 触发 onmessage
        Server-->>Browser: data: chunk3\n\n
        Browser->>Browser: 触发 onmessage
    end
    
    Server-->>Browser: 关闭连接
    Browser->>Browser: 触发 onclose

SSE 是一种服务器向客户端推送事件的技术，特点：

  • 单向通信（服务器 → 客户端）
  • 基于 HTTP 协议
  • 自动重连机制
  • 文本数据传输
  • 事件流格式：data: <content>\n\n

十一、总结

Vercel AI SDK 为构建 AI 应用提供了强大而灵活的工具集：

核心优势

✅ 统一的 API，支持多个 LLM 提供商
✅ 开箱即用的流式传输
✅ 完善的 TypeScript 支持
✅ 框架无关的设计

关键技术点

  • 流协议：SSE 协议实现实时推送
  • 自定义 Transport：转换非标准格式为 SDK 可识别的 Part
  • Part 渲染：分段展示多模态内容
  • 业务场景：断网续流、历史重放、流式取消
