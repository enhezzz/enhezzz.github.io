一、为什么选择 MongoDB？

1.1 使用背景

在现代应用开发中，传统的关系型数据库（如 MySQL）虽然强大，但在某些场景下会遇到瓶颈：

  • 数据模型频繁变化：敏捷开发中，业务模型经常调整，关系型数据库的 schema 变更成本高
  • 非结构化数据存储：日志、用户行为、JSON 格式的 API 响应等数据不适合用表结构存储
  • 高并发写入：社交媒体动态、实时评论、IoT 设备数据等场景需要极高的写入性能
  • 水平扩展需求：数据量增长到单机无法承载，需要分片集群支持
  • 地理位置查询：需要复杂的地理空间索引和查询能力
