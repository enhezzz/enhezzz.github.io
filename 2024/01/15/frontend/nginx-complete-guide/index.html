一、Nginx 是什么？

1.1 定义与特点

Nginx（发音：engine-x）是一个高性能的 HTTP 和反向代理 Web 服务器，同时也提供 IMAP/POP3/SMTP 服务。

核心特点：

  • 🚀 高并发：事件驱动架构，轻松处理万级并发
  • 💾 低内存：相比 Apache，内存占用更低
  • ⚡ 高性能：静态资源处理速度极快
  • 🔄 反向代理：前后端分离架构的标配
  • 📦 负载均衡：多服务器流量分发

二、Nginx 基础架构

2.1 工作原理

Nginx 采用 Master-Worker 多进程模型：

graph TD
    A[Master进程] -->|管理| B[Worker进程1]
    A -->|管理| C[Worker进程2]
    A -->|管理| D[Worker进程N]
    B -->|处理请求| E[客户端连接]
    C -->|处理请求| F[客户端连接]
    D -->|处理请求| G[客户端连接]

    style A fill:#ff6b6b,stroke:#333,stroke-width:2px,color:#fff
    style B fill:#4ecdc4,stroke:#333,stroke-width:2px,color:#fff
    style C fill:#4ecdc4,stroke:#333,stroke-width:2px,color:#fff
    style D fill:#4ecdc4,stroke:#333,stroke-width:2px,color:#fff

Master 进程：

  • 读取配置文件
  • 管理 Worker 进程
  • 处理信号

Worker 进程：

  • 处理客户端请求
  • 事件驱动模型（epoll/kqueue）
  • 非阻塞 I/O

9.1 核心概念

Q1: Nginx 为什么性能这么高？

答：

  1. 异步非阻塞事件驱动模型：使用 epoll/kqueue，单个 Worker 可处理数万并发
  2. 轻量级进程：Master-Worker 架构，Worker 间独立互不影响
  3. 零拷贝技术：sendfile 减少数据在内核态和用户态之间的拷贝
  4. 内存池技术：预分配内存，减少内存分配次数

Q2: Nginx 和 Apache 的区别？

特性 Nginx Apache
架构模型 事件驱动（异步非阻塞） 进程/线程驱动
并发性能 高（万级） 中（千级）
内存占用 低 高
静态资源 极快 较快
动态内容 需要代理 原生支持
配置复杂度 简单直观 复杂但灵活

  • 正向代理：代理客户端，隐藏客户端身份（如 VPN）
  • 反向代理：代理服务器，隐藏服务器信息（如 Nginx）

9.3 性能优化

Q7: Nginx 如何处理惊群问题？

答：通过 accept_mutex 锁机制，确保同一时刻只有一个 Worker 进程监听端口。

Q8: 如何优化 Nginx 性能？

  1. Worker 进程优化：worker_processes auto; 设置为 CPU 核心数
  2. 连接数优化：worker_connections 10240; 增大连接数
  3. 启用缓存：静态资源缓存 + 代理缓存
  4. 开启 Gzip：压缩传输内容
  5. 启用 Sendfile：零拷贝技术
  6. HTTP/2 支持：多路复用提升性能

  3. 超时设置过小
