前端工程师第一次被要求「把项目容器化」的时候，多半会有一种错位感：我写的是浏览器里跑的代码，为什么要关心 Linux 镜像和端口映射？直到遇上这几件事——本地 npm run build 好好的，CI 上构建失败，因为同事的 Node 是 22 而流水线是 18；联调要装 MySQL 和 Redis，换台电脑重来一遍；测试环境刷新页面 404 而生产正常，因为两台机器的 Nginx 配置不一样。
